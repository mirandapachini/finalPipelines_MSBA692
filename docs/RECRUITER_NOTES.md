# Recruiter Notes

## One-sentence summary

This project is an end-to-end environmental analytics application that demonstrates data engineering, SQL modeling, dashboard development, and business-facing product thinking.

## Why it matters

It shows that I can take a real-world idea, gather data from external sources, transform it into useful insights, and package it into a polished experience that is easy to explain and demo.

## Strong interview talking points

- I built a full pipeline rather than a single script.
- I worked across extraction, transformation, storage, and presentation layers.
- I created a product that solves a practical user problem.
- I kept the repository organized and documented for review.
