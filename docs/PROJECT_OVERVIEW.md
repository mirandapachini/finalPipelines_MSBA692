# Project Overview

This repository showcases an end-to-end environmental analytics workflow for gardeners and allergy-sensitive users.

## What the project does

- Collects weather, soil, air quality, and pollen data from Open-Meteo.
- Builds a repeatable ETL process in Python.
- Stores structured data in a PostgreSQL/Supabase environment.
- Presents a dashboard with planting recommendations and health-risk insights.

## Why it is relevant

The project combines data engineering, API integration, SQL modeling, and dashboard development in one cohesive portfolio example.

## Highlights

- Automated ETL workflow
- Interactive dashboard
- SQL schema for analytics use cases
- Clear project structure for future iteration and employer review
