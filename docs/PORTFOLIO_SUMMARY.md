# Portfolio Summary

## Project narrative

This project was built as a practical example of data engineering and analytics product development. It starts with environmental APIs, moves through data cleaning and transformation, and ends with a user-facing dashboard that turns raw signals into meaningful recommendations.

## Why it is compelling

- It shows end-to-end ownership, from data acquisition to presentation
- It reflects real-world tradeoffs in API integration, data quality, and dashboard design
- It combines technical implementation with clear customer value

## Interview talking points

- I designed a workflow that integrates multiple environmental data sources into one coherent dataset.
- I built logic to convert raw observations into actionable gardening advice.
- I created a dashboard that makes complex environmental data easier to interpret.
- I organized the repository so others can understand the architecture and run the project quickly.
